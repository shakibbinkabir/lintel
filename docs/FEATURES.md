# Lintel — features

One row per feature. Upstream ids name the entry of each upstream's feature inventory, not part of this repository (`cc` = coucou-features, `bn` = boring-notch, `vi` = vorssaint-island, `vam` = vorssaint-agents-media, `vau` = vorssaint-audio, `vs` = vorssaint-system, `vw` = vorssaint-windows, `vin` = vorssaint-input, `vcf` = vorssaint-clipboard-files, `vt` = vorssaint-tools, `vc` = vorssaint-capture, `va` = vorssaint-apps, `vsh` = vorssaint-shell, `gap` = gap-assistive-keyboard-click-exception, `base` = base-architecture). The crate column is the crate directory (`crates/<id>/`; the feature's TypeScript is in `src/features/<id>/`). "Later" is what the first version leaves out. Status is `done`, `partial` with what is missing, `planned` or `dropped`.

## Overlap decisions

- **Media**: one GSMTC service (`svc-media`) replaces Coucou's Spotify/Apple Music pills, boring.notch's four controllers and Vorssaint's MediaRemote helper; the boring.notch player layout (art, marquee, seek, slots) wins for the open island, the Vorssaint strip (art left, bars right, title on hover) for the peek strip, the boring.notch sneak peek becomes a `track` notice. Reason: SMTC covers every player, the boring player is the most complete.
- **Notices/HUDs**: Vorssaint's priority and duration table is taken verbatim; boring.notch's two placements (strip, open header) are kept, its Default/Inline split dropped (hardware-notch artefact).
- **Live activities**: Vorssaint's fixed order and pairing rules; boring.notch's "always visible while playing" becomes an off-by-default setting (idle rule).
- **Island open/close**: Coucou's FSM and timers (tested, already working) host Vorssaint's hold-open tokens and Esc step-back and boring.notch's hover delay. Hover-open defaults on because the island is hidden otherwise.
- **Shelf**: one shelf (boring.notch item model and actions, Vorssaint's tile/pile look later); boring's drop-in through the existing WebView2 drop path; Vorssaint's drag detection kept only as the top-band approach zone.
- **Calendar**: boring.notch day-wheel UI; Vorssaint countdown activity; ICS + local reminders first (no account), Cal.com rendered into the same section.
- **Camera**: one `mirror` section (boring mirror, Vorssaint island-camera, Vorssaint camera-preview tool).
- **Lyrics**: one feature (boring music-lyrics, Vorssaint lyrics/island-lyrics); Vorssaint's parser (offset, repeated tags) and opt-in rule.
- **Battery**: boring.notch indicator and popover plus Vorssaint low-battery tint and rest content; Vorssaint system-monitor battery rows reuse the same reader.
- **Volume**: boring hud-volume "alongside" mode first; Vorssaint fine steps and the replace mode share one hook later.
- **Clipboard page / command bar rows / shelf rows**: one `commands` provider contract (defined in the foundation) consumed by the command bar; features expose rows, the bar never reaches into them.
- **Scratchpad**: island section first (Vorssaint island-scratchpad), floating window later; one document store.
- **Window enumeration**: one `svc-windows` catalog (command bar, switcher, layout, window attach, OSK exception).
- **Input hooks**: one `svc-input` hub for Vorssaint input, windows and tools features and boring's replace-HUD mode.
- **Settings**: Vorssaint sidebar/search structure hosts Coucou's existing sections re-homed as pages; boring and Vorssaint per-feature pages come from `defineFeature.settings`.
- **Mascot**: Coucou's engine surface (states, emotes, pills) with Vorssaint's reaction gate later; one original design.
- **Shortcuts**: Coucou's `shortcuts.rs` (AltGr-safe, conflict status) extended with manifest entries; Vorssaint's centre is the Settings page over it; no Ctrl+Alt+printable defaults.
